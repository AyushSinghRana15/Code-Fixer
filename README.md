# Code Fixer Agent

An autonomous agent that connects to GitHub repos, reproduces reported bugs in a sandbox, fixes them, runs the tests until they pass, and opens a pull request explaining the fix. It's designed to run **nearly free** on free-tier LLM providers.

> **Status:** Milestone 0 (planning) is done; Milestone 1 (foundations) is next. Nothing is runnable yet. See [Plan.md](Plan.md) for the full design, decisions and milestones.

## How it works: the harness ladder

    <img src="docs/assets/harness-ladder-light.svg" alt="Code Fixer harness ladder: 11 phases from Intake to Learn, with loops back to the Fix phase when Verify, Review or Feedback fail" width="900">

The agent climbs one rung at a time and only moves up when the current rung passes. When a check fails, it loops back down (A–D) instead of shipping a bad fix. Each rung's chip shows its build status, and the bar at the top tracks overall progress.

| # | Phase | What happens | Runs on |
|---|---|---|---|
| 1 | **Intake** | Read the issue, stack traces and CI logs and turn them into a task spec | cheap LLM |
| 2 | **Env setup** | Clone the repo into a Docker sandbox, detect the stack, install dependencies | code |
| 3 | **Baseline** | Run the existing tests to record what already fails | code |
| 4 | **Reproduce** | Write a test that fails because of the bug | LLM |
| 5 | **Localize** | Find suspect files from the stack trace, ripgrep and symbols | code |
| 6 | **Fix loop** | Edit, run targeted tests, read failures, repeat | LLM |
| 7 | **Verify** | Full suite, lint and type-check, with no new failures vs. the baseline | code |
| 8 | **Review** | A critic checks the diff; a guard rejects changes that weaken tests | LLM |
| 9 | **Deliver** | Push a branch and open a PR with the root cause and test results | cheap LLM |
| 10 | **Feedback** | Act on PR review comments and CI results | LLM |
| 11 | **Learn** | Save the trajectory, repo memory and eval metrics for next time | cheap LLM |

Steps that run as plain **code** use no LLM requests, which keeps the agent within free-tier limits.

<details>
<summary><b>Loops and guardrails</b></summary>

| Loop | From → To | When |
|---|---|---|
| A | Verify → Fix loop | The full suite shows new failures |
| B | Review → Fix loop | The critic or the test-tamper guard rejects the diff |
| C | Feedback → Fix loop | A reviewer comments, or CI goes red on the PR |
| D | Fix loop → Localize | Stuck: the same failure repeats N times |

On every rung: request and time budgets, stuck detection, automatic provider failover, and a written report if the agent gives up.
</details>

## Planned features

- CLI first: `fixer run --repo owner/name --issue 123`
- Supports Python, JavaScript/TypeScript and Java repos
- A Docker sandbox per job, with no network during test runs and no secrets inside the container
- An LLM router across free providers (OpenRouter, Gemini, NVIDIA, Groq, Mistral, Ollama, or any OpenAI-compatible endpoint) with quota tracking
- **Multiple providers:** choose your primary provider and fallback order. If a key expires, credits run out or a daily quota is hit, the agent switches to the next provider automatically, even mid-job.
- **Secure key vault:** API keys are stored encrypted (AES-256-GCM) in a local SQLite DB, with the master key in your OS keychain. Keys are never logged and never passed into the sandbox.
- Budgets on LLM requests, iterations and time, plus stuck detection
- Full trajectory logs so every run can be replayed
- **Local web dashboard** (Next.js): live jobs view and a page to manage providers and keys
- Later: a GitHub App with webhook triggers, a PR review-comment loop and parallel candidate fixes

## Requirements (planned)

- Python 3.12+
- Docker (on macOS: `brew install colima docker && colima start`)
- A GitHub token with repo access
- At least one free LLM API key (OpenRouter recommended)

## Managing providers (planned)

```bash
fixer providers add openrouter        # prompts for the key, validates it, stores it encrypted
fixer providers add nvidia
fixer providers order openrouter nvidia gemini   # primary first, then fallbacks
fixer providers list                  # status, masked keys, today's usage
fixer providers rotate-key openrouter # replace an expired key
```
